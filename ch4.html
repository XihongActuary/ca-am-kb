4.1线性回归 高频★★★

一切从 y=β₀+β₁x+ε 出发：OLS 给系数，R² 给解释力，t/F 检验给显著性。

① OLS 估计

β̂₁ = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)² = (nΣxᵢyᵢ − ΣxᵢΣyᵢ) / (nΣxᵢ² − (Σxᵢ)²)
β̂₀ = ȳ − β̂₁·x̄
思想：最小化残差平方和 RSS=Σ(yᵢ−β̂₀−β̂₁xᵢ)²。回归线必过 (x̄, ȳ)。

② 经典假设与推断

假设内容违反后果
线性E(y|x) 与 x 线性相关偏误、R² 无意义
独立误差项相互独立标准误失真（时间序列常见）
同方差Var(εᵢ)=σ² 恒定t/F 检验失效（异方差）
正态ε∼N(0,σ²)小样本推断失效
R² = 1 − SSE/SST = (SSR/SST)，F = (SSR/1)/(SSE/(n−2)) = (R²/1)/((1−R²)/(n−2))
一元回归中 t² = F；R² 就是 x 与 y 样本相关系数 r 的平方。易错：R² 高不代表因果，也不代表模型合适（非线性数据 R² 也可能不低）。

4.2广义线性模型 GLM 高频★★★

GLM = 线性回归的三处松绑：响应变量不必正态（指数族）、均值经连接函数挂钩性预测、方差可以随均值变。它是费率厘定的行业标准工具。

① 指数族与连接函数

f(y;θ,φ) = exp{ [yθ − b(θ)] / a(φ) + c(y,φ) }
g(E[Y]) = η = β₀ + β₁x₁ + … + βpxp
g 为连接函数；典型搭配：正态—恒等、泊松—log（乘法模型）、二项—logit、伽马—log 或倒数。方差结构由指数族自动决定：Var(Y)=φ·V(μ)。
响应变量分布常用连接精算场景
出险次数（计数）泊松 / 负二项log频数模型：车险件数
案均赔款（正连续）伽马log / 倒数强度模型：件均赔款
是否出险（0/1）二项logit投保/出险概率
总赔款（ Tweedie）复合泊松-伽马log纯保费直接建模（0点堆积+连续）

② 模型比较

偏差 Deviance = 2φ·[ℓ(饱和) − ℓ(模型)]　　AIC = −2ℓ + 2p，　BIC = −2ℓ + p·ln(n)
选模型：AIC/BIC 越小越好；BIC 对参数个数惩罚更重。偏差除以自由度 ≈ 1 表示离散拟合良好；泊松数据 >>1 提示过散布（换负二项）。
实务链接：GLM 是车险费率因子的标准工具——「从频率 × 强度到纯保费」两步走，正是《风险模型：基于R》第6章前后各章的实战主线。
GLM 诊断与选择（补强）：残差用 deviance 残差 / Pearson 残差（不是普通残差）；离差 D=2(ℓ_sat−ℓ_model)，嵌套模型差 ∼ χ²(Δdf)——与线性回归的 F 检验对应；过离散（Var>均值，泊松失灵）→ 负二项或 quasi-Poisson；零膨胀过多 → hurdle/ZIP。交互项与共线性用 VIF>10 预警。
OLS 的原理基石：高斯–马尔可夫定理——在线性、无完全共线、误差零均值、同方差、无自相关五条经典假设下，OLS 估计量是最优线性无偏估计（BLUE）：在所有线性无偏估计中方差最小。注意两点：① 定理不需要正态假设——正态只在做小样本 t/F 检验时才需要；② 同方差或无自相关被破坏时，OLS 仍无偏但不再「最优」，标准误失真 → 用稳健标准误（White/Newey–West）。简答题考「写出五条假设并说明定理结论」。

4.3惩罚线性回归 中频★★

变量多、样本少、共线性重？给 OLS 上「惩罚项」，用一点偏差换大幅方差下降。
Ridge：β̂ = argmin{ Σ(yᵢ−β₀−xᵢᵀβ)² + λ·Σβj² }　解析解 (XᵀX+λI)−1Xᵀy
Lasso：β̂ = argmin{ Σ(yᵢ−β₀−xᵢᵀβ)² + λ·Σ|βj| }　无解析解（数值优化）
λ=0 退化为 OLS；λ→∞ 系数全部压向 0。
对比维度Ridge（L2）Lasso（L1）
惩罚形式系数平方和系数绝对值之和
系数收缩整体缩小，不为零可精确压到零 → 自动变量选择/稀疏解
共线性非常有效（稳定估计）组内强共线时倾向保留其一
解的形式闭式解无闭式解
共同点：都需对变量标准化后施加惩罚；λ 都用交叉验证选择；都属于收缩方法——牺牲少量偏差，换取方差显著下降，预测误差更小。

4.4真题链接 题

2014·A3OLS 基本计算 n=10，Σx=100，Σy=400，Σxy=4300，Σx²=1100。求回归方程。
骨架：β̂₁=(10×4300−100×400)/(10×1100−100²)=3000/1000=3；β̂₀=40−3×10=10；ŷ=10+3x。
展开详尽解答

β̂₁=(nΣxy−ΣxΣy)/(nΣx²−(Σx)²)=(43000−40000)/(11000−10000)=3000/1000=3。

x̄=10，ȳ=40，β̂₀=40−3×10=10。回归方程 ŷ=10+3x。

概念Ridge 与 Lasso 辨析（简答模板）：为什么 Lasso 能做变量选择而 Ridge 不能？
骨架：① L1 惩罚在系数处不可导；② 等值线是菱形/尖点在坐标轴上；③ 最优解常落在顶点=系数恰为 0；④ L2 圆滑无尖点，只收缩不归零。
展开详尽答案

几何解释：损失函数的等值线（椭圆）与惩罚区域相切。L1 惩罚区域是菱形，顶点落在坐标轴上——最优解若在顶点处，对应系数恰为零，即该变量被剔除；多个变量可同时归零，形成稀疏解。L2 惩罚区域是圆盘，处处光滑无尖点，切点一般不在坐标轴上，系数只会整体收缩而不会精确为零，因此 Ridge 保留全部变量、不做选择。

加分点：两者都可由「贝叶斯先验」解释——Ridge 对应正态先验，Lasso 对应 Laplace 先验；λ 用 K 折交叉验证选取。
