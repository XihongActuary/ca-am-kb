一风险理论 权重30%

2011·A3泊松增量 N(t) 是强度 λ=2 的泊松过程，求 P{N(3)−N(1) ≤ 1}。
骨架：增量长度 2 → Poisson(4)；P=e−4(1+4)=5e−4≈0.0916。
展开详尽解答

N(3)−N(1)∼Poisson(2×2=4)。P{≤1}=P(0)+P(1)=e−4(1+4)=5×0.01832≈0.0916。

2012·A3非齐次泊松 强度 λ(t)=t（t≥0），求 P{N(2)=1}。
骨架：m(2)=∫₀²t dt=2；P=2e−2≈0.2707。
展开详尽解答

m(2)=t²/2|=2。P{N(2)=1}=e−2·2≈0.2707。

2014·A3三状态马氏链 转移矩阵 P 中 P₁₁=0.5,P₁₂=0.5,P₂₁=0.2,P₂₂=0.8（两状态）。初始在状态 1，求两步后回到状态 1 的概率与极限分布。
骨架：P¹¹⁽²⁾=0.5²+0.5×0.2=0.35；π₁=0.2/(0.5+0.2)=2/7≈0.2857。
展开详尽解答

两步：P₁₁(2)=P₁₁²+P₁₂P₂₁=0.25+0.10=0.35。极限：π₁=0.5π₁+0.2π₂ ⇒ 0.5π₁=0.2(1−π₁) ⇒ π₁=0.2/0.7=2/7≈0.2857。两步概率 0.35 高于极限 0.2857，正在振荡收敛。

2015·A3次数分布反推 理赔次数 N 满足 E(N)=2，Var(N)=4。判断分布类型并求参数。
骨架：方差>均值 → 负二项；rβ=2，rβ(1+β)=4 → β=1，r=2。
展开详尽解答

泊松方差=均值，二项方差<均值，负二项方差>均值 → 负二项 NB(r,β)。rβ=2、rβ(1+β)=4 ⇒ 1+β=2 ⇒ β=1, r=2。P₀=(1+β)−r=1/4。

2017·A3盈余过程破产判断 u=900，c=100/年，首笔理赔 5000 在 T∼U[0,50] 时刻发生。求破产概率（只考虑该笔理赔）。
骨架：900+100T<5000 ⇒ T>41；P=(50−41)/50=0.18。
展开详尽解答

U(T)=900+100T−5000<0 ⇔ T>41。T∼U[0,50] ⇒ P(T>41)=9/50=0.18。

2005·A3MGF 反推分布 MU(t)=(1−2t)−9，求 Var(U)。
骨架：识别 Γ(9,2)：Var=9×2²=36。
展开详尽解答

(1−βt)−α 是 Γ(α,β) 的 MGF → U~Γ(9,2)，E=18、Var=αβ²=36（答案 D）。硬求导：E(U)=18，E(U²)=360，Var=36。详见 CH.01 题库精粹。

1000题·P149泊松细分（稀释） 月理赔事件~泊松(10)，每次理赔 5% 概率超 2 万元。求半年内至少 2 次超 2 万的概率。
骨架：细分仍泊松：半年~Poisson(3)；P(N≥2)=1−4e−3≈0.8009。
展开详尽解答

泊松按独立概率 v 筛选后仍是泊松，参数 λv=0.5/月；半年 3。P(N≥2)=1−e−3(1+3)=1−4e−3（答案 B）。详见 CH.01。

1000题·P162正态 vs 平移伽马 λ=12 复合泊松、单笔 U[0,1]，比较两法求 P(S<10) 的差异。
骨架：正态 Φ(2)=0.97725；平移伽马 (x₀,α,β)=(−14/3, 256/9, 8/3)→0.9682；差≈0.009。
展开详尽解答

E(S)=λp₁=6、Var=λp₂=4、三阶中心矩=λp₃=3。平移伽马三参数：x₀=μ−2σ⁴/γ³、α=4σ⁶/γ⁶、β=2σ²/γ³（σ²=Var，γ³=三阶中心矩）。正态忽略正偏度→右尾高估（答案 E）。完整推导见 CH.01 题库精粹。

1000题·P76通胀×免赔额杠杆 P(X=1000k)=1/6（k=1..6），免赔 1500→通胀 5% 后免赔 1600。求理赔额期望增长率。
骨架：2010 年期望赔付 2500 → 2011 年 2600；增长率 4%。
展开详尽解答

E(X)=3500、E(X∧1500)=1416.67 → E⁽²⁰¹⁰⁾(Y)=2500；通胀后等效免赔比较得 2600。增长率=100/2500=4%（答案 B）——免赔额吸收了部分通胀。详见 CH.01。

二生存分析 权重15%

2011·A3De Moivre 生命表 S(x)=1−x/100（0≤x≤100）。求 μ40 与 ₅p₄₀。
骨架：μx=1/(100−x) → μ₄₀=1/60；₅p₄₀=S(45)/S(40)=(55/100)/(60/100)=11/12≈0.9167。
展开详尽解答

F=1−S=x/100，f=1/100，μx=f/S=1/(100−x)，μ₄₀=1/60≈0.0167。₅p₄₀=S(45)/S(40)=0.55/0.60=11/12≈0.9167。

2013·A3危险率积分可加 已知 ₂pₓ=0.98，₃px+2=0.95。求 ₅px。
骨架：₅px=₂px×₃px+2=0.98×0.95=0.931。
展开详尽解答

链式法则：₅px=₂px·₃px+2=0.931。本质是 e−∫₀⁵μ=e−∫₀²μ·e−∫₂⁵μ，积分可加。

2016·A3K-M 估计 8 人观察：死亡发生于 t=2（风险数8）、t=5（风险数5，期间删失2人）、t=7（风险数3）。求 Ŝ(7)。
骨架：(1−1/8)(1−1/5)(1−1/3)=0.875×0.8×0.6667≈0.4667。
展开详尽解答

Ŝ(7)=Π(1−dᵢ/nᵢ)=(7/8)(4/5)(2/3)=56/120≈0.4667。注意 t=5 的风险数已剔除此前死亡与删失者。

1000题·P54三大分数年龄假设 qₓ=0.12，求 UDD / 常死力 / Balducci 下的 ₁/₃qx+1/2。
骨架：0.042553 / 0.061917 / 0.043478——三个都对。
展开详尽解答

UDD：⅓q/(1−½q)；CF：1−(1−q)1/3；Balducci：⅓q/(1−⅔q)。答案 E（全对）。分母 0.94 / 无 / 0.92——高频对比题，详见 CH.02 题库精粹。

1000题·P19多重减因转换 q′⁽¹⁾=0.2、q′⁽²⁾=0.4（均匀），求 q⁽²⁾。
骨架：q⁽ᵗ⁾=0.52；q⁽²⁾=(ln0.6/ln0.48)×0.52=0.3619。
展开详尽解答

均匀假设转换公式 q⁽ʲ⁾=[ln(1−q′⁽ʲ⁾)/ln(1−q⁽ᵗ⁾)]·q⁽ᵗ⁾（答案 C）。详见 CH.02。

1000题·P6多重生命协方差 T(x)、T(y) 独立，E 各为 4，Cov[T(xy),T(x̄y)]=0.09。求 E[T(xy)]。
骨架：16−exy(8−exy)=0.09 → exy=3.7。
展开详尽解答

核心恒等式 ex̄y=eₓ+e_y−exy，独立下 E[T(xy)T(x̄y)]=eₓe_y=16，解二次方程（答案 C）。详见 CH.02。

1000题·P214K-M vs Nelson-Aalen 4 只小白鼠死亡时间 2,4,5,9。求 Ŝ⁽ᴷᴹ⁾(8)−Ŝ⁽ᴺᴬ⁾(8)。
骨架：0.25−e−13/12=0.25−0.3385≈−0.09。
展开详尽解答

KM=(3/4)(2/3)(1/2)=0.25；NA：Λ̂=1/4+1/3+1/2=13/12 → Ŝ=e−13/12=0.3385。恒有 ŜNA≥ŜKM（ln(1−x)≤−x），方向题秒答（答案 C）。详见 CH.02。

三随机模拟 权重10%

2012·A3反函数法 X 服从 λ=0.5 的指数分布，取 u=0.8，用反函数法求 x。
骨架：x=−ln(1−u)/λ=−ln0.2/0.5≈3.2189。
展开详尽解答

F(x)=1−e−λx=u ⇒ x=−ln(1−u)/λ=−ln(0.2)/0.5=1.6094/0.5≈3.219。用 −ln(u)/λ 亦可（同为均匀）。

概念样本容量（真题改编） 用模拟估计 E(X)，置信水平不变、误差容忍减半，模拟次数如何变化？
骨架：n∝(zσ/ε)²，ε 减半 → n 变为 4 倍。
展开详尽解答

由 n≥(zα/2σ/ε)²，其他不变时 n 与 ε² 成反比：ε 减半 ⇒ n 放大 4 倍。根号代价：精度线性提升，代价平方增长。

1000题·P319Box-Muller 数值代入 u₁=0.6341、u₂=0.5791，求生成的标准正态随机数。
骨架：R=√(−2ln u₁)=0.9545；X₁=−0.8399、X₂=−0.4536。
展开详尽解答

X₁=R·cos(2πu₂)、X₂=R·sin(2πu₂)；2πu₂=208.5°，cos=−0.8799、sin=−0.4752 → X₁=−0.8399、X₂=−0.4536（答案 D）。半径只由 u₁ 决定。详见 CH.03 题库精粹。

1000题·P319离散逆变换（负二项） 负二项 k=6、p=0.6，u₁=0.345、u₂=0.789。求对应随机数。
骨架：累积表首个 ≥u 的 n：u₁→3、u₂→6，答案 (3,6)。
展开详尽解答

P(N≤2)=0.3155<0.345≤P(N≤3)=0.4827 → n=3；P(N≤5)=0.7536<0.789≤P(N≤6)=0.8419 → n=6（答案 B）。口诀：累积概率第一个盖过 u 的 n。

四回归分析 权重15%

2015·A3决定系数 一元回归中 n=20，SST=500，SSE=180。求 R² 与 r，并检验解释力（F 统计量）。
骨架：R²=1−180/500=0.64；r=0.8；F=(320/1)/(180/18)=32 > F₀.₀₅(1,18)≈4.4，显著。
展开详尽解答

R²=SSR/SST=(500−180)/500=0.64，r=√0.64=0.8。F=(SSR/1)/(SSE/(n−2))=320/10=32，远超临界值 4.41，回归高度显著。一元情形 t=√F≈5.66。

改编泊松回归预测 log μ = 0.5 + 0.3x（车险出险次数模型）。x=2（两年车龄因子）时年均出险次数？
骨架：μ=e0.5+0.6=e1.1≈3.00。
展开详尽解答

泊松回归连接函数 g=log：μ=e0.5+0.3×2=e1.1≈3.00。系数 0.3 的含义：x 每增 1，均值乘 e0.3≈1.35（乘法效应）。

五时间序列 权重10%

2014·A3ACF/PACF 识别 某序列 ACF 在滞后 2 阶后截尾，PACF 拖尾。最合适的模型？
骨架：ACF q 阶截尾 + PACF 拖尾 → MA(2)。
展开详尽解答

识别规则：ACF 截尾阶数=q → MA(q)；PACF 截尾阶数=p → AR(p)。此处 MA(2)；若两者皆拖尾则 ARMA(p,q)。

2017·A3AR(2) 稳定性 Xt=0.8Xt−1+0.3Xt−2+εt 是否平稳？
骨架：φ₂+φ₁=1.1>1 → 不稳定（特征根在单位圆外）。
展开详尽解答

条件：|φ₂|<1 ✔（0.3）；φ₂+φ₁=1.1 ✘（须<1）。特征方程 λ²−0.8λ−0.3=0 的根为 (0.8±√1.84)/2 ≈ 1.078, −0.278，|λ₁|>1 → 非平稳。

六机器学习 权重20%

2016·A3信息增益计算 数据集 16 个样本（8 正 8 负），按属性 A 分裂后两个子集各 8 个样本且全为纯类。求信息增益。
骨架：H(D)=1 bit；H(D|A)=0；增益=1。
展开详尽解答

H(D)=−0.5log₂0.5−0.5log₂0.5=1。分裂后子集纯：H(D|A)=½×0+½×0=0。Gain(A)=1−0=1 bit（完美分裂）。若用基尼：1−(0.5²+0.5²)=0.5 → 分裂后 0，下降 0.5。

概念监督 vs 无监督（多选辨析） 下列属于无监督学习的有：A) K-means 客户分群；B) 逻辑回归续保预测；C) PCA 指标压缩；D) 决策树核保评级。
骨架：A、C（无标签；B、D 有标签属监督学习）。
展开详尽解答

判断标准：是否使用带标签的 (x,y)。A 聚类、C 降维只用 x → 无监督；B 分类、D 分类树 → 监督。强化学习是第三类（延迟奖励驱动），与两者并列。

概念指标选择（情景题） 欺诈识别中欺诈率仅 1%，模型把所有保单判为「非欺诈」的准确率高达 99%。该模型好吗？应看什么指标？
骨架：不好——准确率被多数类淹没；应看召回率/精确率/F1/AUC。
展开详尽解答

不平衡数据下准确率失真（全判多数类即得 99%）。该模型召回率=0（一个欺诈都没抓到）。应关注：召回率（欺诈抓回比例）、精确率（报警可信度）、F1 或 AUC；代价敏感学习/重采样也是标准对策。
