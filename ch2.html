2.1生存模型理论 高频★★★

新出生个体的死亡年龄 X≥0 是随机变量，一切围绕 S(x)=P(X>x) 展开。这页公式必须形成「肌肉记忆」。

① 基本公式体系

S(x)=P(X>x)，S(0)=1，S(+∞)=0　F(x)=1−S(x)　f(x)=F′(x)=−S′(x)
危险率（死亡力）：μx = −S′(x)/S(x) = f(x)/S(x) = −[ln S(x)]′
tPx = P(X>x+t | X>x) = S(x+t)/S(x) = e−∫₀t μ(x+s)ds
t|u qx = P(x+t < X < x+t+u | X>x) = [S(x+t) − S(x+t+u)] / S(x)
教B4第2章。三件套关系：S ↔ μ 互推（S=e^{−∫μ}），tPx 是条件生存概率，t|u qx（延期死亡概率）= tPx·uqx+t。

② 剩余寿命

T(x)=X−x 为完全剩余寿命；K(x)=⌊T(x)⌋ 为整值剩余寿命（死亡发生在哪一年内）。教B4第2章

E[T(x)] = e̊x = ∫₀∞ t·μ(x+t)·tpx dt = ∫₀∞ tpx dt
ex = Σk=1∞ kpx　（整值剩余寿命期望 = 生存概率求和）
两个期望相差约 0.5（均匀死亡假设下 e̊x≈ex+0.5）。易错：求和从 k=1 开始，不是 k=0。

③ 选择—终极表

投保时的核保信息会「过期」：选择年龄 [x] 后 n 年的死亡率介于「刚选择」与「终极」之间，记号 l[x]+n：教B4第2章

l[x]+n = l[x] + n　（n < t，t 为选择期）　　l[x]+n = lx+n　（n ≥ t，进入终极）
取数规则：查表时先看选择期——n 在选择期内走选择列，超出选择期直接用终极列。
冲刺例（生存概率拼接） 已知 ₃p₁₀=0.95，₂p₁₁=0.96，∫₁₁¹⁵ μxdx=0.07。求 ₅p₁₀。
骨架：① ₅p₁₀=₃p₁₀·₂p₁₃；② ₂p₁₃=₂p₁₁·e−∫₁₃¹⁵μ；③ ∫₁₃¹⁵=0.07−(−ln0.96)=0.0292；④ 结果≈0.9226。
展开详尽解答

₅p₁₀ = ₃p₁₀ × ₂p₁₃ = ₃p₁₀ × ₂p₁₁ × e−∫₁₃¹⁵ μxdx。

由 ₂p₁₁=e−∫₁₁¹³μ 得 ∫₁₁¹³μ=−ln0.96=0.0408，故 ∫₁₃¹⁵μ=0.07−0.0408=0.0292。

₅p₁₀ = 0.95×0.96×e−0.0292 = 0.912×0.9712 ≈ 0.8857。

点评：这类题的关键是「把积分区间拆开」，危险率积分像路程一样可加。

① 演算器：tPx 与延期死亡概率（常数危险率假设）

tpx —
t|u qx —
常数危险率下 tPx=e−μt；t|u qx=tPx(1−e−μu)。
记忆口诀：「生存除一除，危险负对数；积分可拆段，条件要乘链」——S→μ→tPx 一条线，区间积分可加，条件概率按链式乘。

2.2生存分析 中频★★

真实数据不会等你观察全员死亡——删失是生存数据的常态，估计生存函数要靠乘积限方法。

① 数据类型

类型含义处理要点
完整数据观察到确切死亡/失效时刻直接用经验分布
右删失只知「存活超过某时刻」（退保、观察期结束）K-M 处理的主体
左删失/区间删失只知事件发生在某时刻之前/某区间内需专门方法，考试以概念辨析为主
左截断个体进入观察前已死亡则不出现条件化处理

② Kaplan-Meier 与 Nelson-Aalen

KM（乘积限）：Ŝ(t) = Πtᵢ ≤ t (1 − dᵢ/nᵢ)　（dᵢ 为 tᵢ 时死亡数，nᵢ 为风险数）
NA：Ĥ(t) = Σtᵢ ≤ t dᵢ/nᵢ，Ŝ(t) ≈ e−Ĥ(t)
教B4第2章；R 实战见《基于R的保险损失预测》。两者都用「时点风险集」nᵢ：删失个体在删失时刻之后不再计入风险集；若删失与死亡同时刻，习惯上删失个体仍计入当期风险集。
易错：nᵢ 是「恰好处于风险中的个体数」= 进入未死亡未删失者。删失个体从删失时点起移出；死亡时刻相同者一并计入 dᵢ。

③ 生命表

生命表是大样本分组的生存分析：lx 存活数、dx=lx−lx+1 死亡数、qx=dx/lx；中心死亡率 mx=dx/Lx；完整未来生存人年数 Tx=ΣLx+k。编制原理（了解）：假设均匀分布 UDD、常数危险或 Balducci 假设，把连续模型落到离散年龄组。教B4第2章

② 演算器：Kaplan-Meier 估计

Ŝ(时点3) —
NA 累积危险 Ĥ —
输入 0 表示该时点无死亡。Ŝ=Π(1−dᵢ/nᵢ)；Ĥ=Σdᵢ/nᵢ。
实务链接：K-M 曲线是药品临床试验、退保分析（persistency）、再保险定价里最常用的图；精算师的「保单继续率」本质就是带删失的生存估计。

2.3真题链接 题

2012·A3危险率与生存函数互推 已知 S(x)=e−x²/200（x≥0）。求 μ40 与 ₁₀p₄₀。
骨架：μx=−[lnS]′=x/100；μ₄₀=0.4；₁₀p₄₀=S(50)/S(40)=e−(2500−1600)/200=e−4.5≈0.0111。
展开详尽解答

lnS(x)=−x²/200，求导得 μx=x/100。μ₄₀=0.4。

₁₀p₄₀=S(50)/S(40)=e−50²/200/e−40²/200=e−(2500−1600)/200=e−4.5≈0.0111。

点评：Weibull 型 S(x)（x² 项）是命题最爱——记住 μx=−(lnS)′ 这一步万能。

2016·A3K-M 风险集判断 10 人观察，第 2 年死亡 1 人、删失 1 人，第 4 年死亡 1 人。用 K-M 估计 Ŝ(4)。
骨架：时点2风险集 n=10，(1−1/10)=0.9；时点4风险集 n=8（10−1死−1删），(1−1/8)=0.875；Ŝ(4)=0.7875。
展开详尽解答

t=2：风险集 10，d=1 → 因子 0.9；随后 1 人在第 2 年末删失。

t=4：风险集 10−1−1=8，d=1 → 因子 0.875。

Ŝ(4)=0.9×0.875=0.7875。

2.4题库精粹 题逐题吸收

逐页取自《A3过关必做1000题》生存分析·生命表·经验模型·参数估计各章（书页号已标注），含答案与解析。
1000题·P54 真题三大分数年龄假设对比 qx=0.12，分别求 UDD、常死力（CF）、Balducci 三种假设下的 ₁/₃qx+1/2。
骨架：UDD：⅓q/(1−½q)=0.04/0.94=0.042553；CF：1−(1−q)1/3=1−0.881/3=0.061917；Balducci：⅓q/(1−⅔q)=0.04/0.92=0.043478。三个数值全对 → 答案 E。
展开详尽解答

UDD（死亡均匀）：ₜqx+s=t·qx/(1−s·qx)，s=1/2、t=1/3 → 0.04/0.94。

常死力：生存函数 (1−q)t → 1−(0.88)1/3。

Balducci（双曲线）：ₜq=t·q/(1−(1−t)q)，t=1/3 → 0.04/0.92。

三种假设的 ₁/₃qx+1/2 公式是生存分析最高频对比题，把三个分母焊死：0.94 / 无分母 / 0.92。

1000题·P19多重减因转换 双减因独立终止率 q′ₓ⁽¹⁾=0.2、q′ₓ⁽²⁾=0.4，各原因年内均匀。求 qₓ⁽²⁾（由原因2导致的终止概率）。
骨架：p⁽ᵗ⁾=p′⁽¹⁾p′⁽²⁾=0.48 → q⁽ᵗ⁾=0.52；q⁽²⁾=[ln(1−q′⁽²⁾)/ln(1−q⁽ᵗ⁾)]·q⁽ᵗ⁾=(ln0.6/ln0.48)×0.52=0.3619。答案 C。
展开详尽解答

均匀假设下的标准公式：qₓ⁽ʲ⁾=[ln(1−q′ₓ⁽ʲ⁾)/ln(1−qₓ⁽ᵗ⁾)]·qₓ⁽ᵗ⁾。

ln(0.6)=−0.5108，ln(0.48)=−0.7340，比值 0.6959，乘 0.52 得 0.3619。

方向记忆：由「独立率」转「联合率」用 ln 比值缩放；分子 ln(1−q′⁽ʲ⁾)、分母 ln(1−q⁽ᵗ⁾)。

1000题·P19双减因积分拆分 某双减因模型积分得 ₅qₓ⁽¹⁾=0.156、₅qₓ⁽²⁾=0.115。验证总终止率。
骨架：₅qₓ⁽ᵗ⁾=0.156+0.115=0.271。
展开详尽解答

每种原因：₅q⁽ʲ⁾=∫₀⁵ pₓ₊ₜ⁽ᵗ⁾·μₓ₊ₜ⁽ʲ⁾dt，其中总生存概率 p⁽ᵗ⁾=∏ₖp′⁽ᵏ⁾（本题结构 (1−t/30)(1−t/40)）。

多重减因可加性：总终止率=各原因终止率之和=0.271。

1000题·P6多重生命协方差 T(x)、T(y) 独立，E[T(x)]=E[T(y)]=4，Cov[T(xy), T(x̄y)]=0.09。求 E[T(xy)]。
骨架：用 ex̄y=eₓ+e_y−exy 与独立恒等式列二次方程，解得 exy=3.7。答案 C。
展开详尽解答

独立下：E[T(xy)·T(x̄y)]=eₓ·e_y=16（联合生存与最后生存的未来期望乘积）；而 Cov=E[积]−exy·ex̄y=16−exy(8−exy)=0.09。

整理：e²xy−8exy+15.91=0 → exy=4−√0.09/2×2? 直接求根：exy=(8−√(64−63.64))/2=(8−0.6)/2=3.7。

核心恒等式：ex̄y=eₓ+e_y−exy——「最后生存=先加起来再减去同时活着」。

1000题·P39生命表代数式 l_z=1000(1−z/120)。求 ₂₀p₃₀ / (₂₀|₅q₂₅)。
骨架：₂₀p₃₀=7/9；₂₀|₅q₂₅=1/19；比值=(7/9)×19=14.778。答案 D。
展开详尽解答

₂₀p₃₀=(1−50/120)/(1−30/120)=70/90=7/9；₂₀|₅q₂₅=(l₄₅−l₅₀)/l₂₅=(5/120)/(95/120)=1/19。

比值=(7/9)÷(1/19)=133/9≈14.778。生命表题全部化成 l 值之比，别硬背概率公式。

1000题·P39常死力延期死亡 20≤x≤25 时 μₓ=0.001（常数）。求 ₂|₂q₂₀。
骨架：∫₂⁴ e−0.001t×0.001dt=e−0.002−e−0.004≈0.002。答案 B。
展开详尽解答

常死力下 ₜp₂₀=e−0.001t：₂|₂q₂₀=e−0.002−e−0.004=0.998002−0.996008=0.001994≈0.002。

区间短、μ 小时 ≈ μ×2=0.002，量级校验秒杀选项。

1000题·P214乘积估计 vs Nelson-Aalen 4 只小白鼠死亡时间 2,4,5,9。求 Ŝ⁽ᴷᴹ⁾(8)−Ŝ⁽ᴺᴬ⁾(8)。
骨架：KM=(3/4)(2/3)(1/2)=0.25；NA：Λ̂=1/4+1/3+1/2=13/12，Ŝ=e−13/12≈0.3385；差≈−0.09。答案 C。
展开详尽解答

K-M：Π(1−dᵢ/nᵢ)=0.75×0.6667×0.5=0.25。N-A：Λ̂(8)=13/12，ŜNA=e−13/12=0.3385。

差=0.25−0.3385≈−0.09。

不等式记忆：ln(1−x)≤−x ⇒ ŜNA ≥ ŜKM 恒成立（无删失时），方向题秒答。

1000题·P214带退出的乘积估计 50 位 60 岁退休职工一年期寿险：第一季度末死 2 人，60⅔ 岁 6 人退出，第三季度末死 3 人。求 q̂₆₀。
骨架：上半段 1−2/50=0.96；下半段风险集 50−2−6=42，1−3/42=13/14；q̂=1−0.96×13/14≈0.109。答案 A。
展开详尽解答

按退出时点分段：每段用「段初风险集」，退出者离开风险集。

q̂₆₀=1−(1−2/50)(1−3/42)=1−0.96×0.9286≈0.109。

乘积估计的退出处理：先发生的退出先减人数——顺序搞错整题全错。

1000题·P214乘积估计反解退出数 10 名 100 岁老人：t=2 死 1 人、t=4 有 x 人退出、t=4.5 死 1 人。若 Ŝ(5)=0.75，求 x。
骨架：(9/10)×(8−x)/(9−x)=0.75 → x=3。答案 B。
展开详尽解答

t=2：风险集 10，因子 9/10。t=4.5：风险集 10−1−x=9−x，因子 (8−x)/(9−x)。

(9/10)(8−x)/(9−x)=3/4 → 6(8−x)=7.5? 变形 (8−x)/(9−x)=5/6 → 48−6x=45−5x → x=3。

反解题套路：把未知数放进风险集列方程——考「理解」不考「记忆」。

1000题·P234分位数法估两参数 F(x)=(x/θ)γ/[1+(x/θ)γ]，11 个样本，用 40% 与 80% 分位数估计 θ、γ，求 θ̂+γ̂。

1000题·P256K-S 统计量 样本 0.1,0.2,0.5,1.0,1.3，原假设 f(x)=2(1+x)−3。求 Dₙ。

2.5生命表编制原理：从经验数据到一张表 原理必考★★

考纲原句：「了解生命表编制原理」。编制就是把散落的观察数据加工成一张 qₓ 表的流水线：数据 → 暴露数 → 死亡率估计 → 修匀 → 外推补尾。简答题考「流程与各环节作用」，计算题考「暴露数与中心死亡率」。

编制流水线五步（简答模板）

① 数据收集：观察期（如日历年）内的保单/人口记录，记录进入、退出（死亡/退保/期满）时点；
② 暴露数计算：风险数 rₓ = 处于 x 岁被观察的「人年数」——精确法按积分 ∫lx+tdt，估算法按「期初人数 − 死亡数的一半」（死亡均匀假设下）；
③ 死亡率估计：q̂ₓ = 死亡数 dₓ / 暴露数 rₓ（或用 K-M/N-A 修正删失）；
④ 修匀：Whittaker–Henderson / 参数曲线（Gompertz 等），在「拟合优度 ↔ 光滑度」间权衡，见 model.html §5；
⑤ 补尾与列表：高龄段数据稀薄，用 Gompertz/Makeham 外推至 ω，得到完整表格。

中心死亡率 mₓ 与 qₓ 的关系

中心死亡率 mₓ = ∫₀¹ lx+tμx+tdt / ∫₀¹ lx+tdt = dₓ / Lₓ（Lₓ 为平均生存人年数）
UDD 下：qₓ = mₓ / (1 + mₓ/2)；常死力下：qₓ = 1 − e−mₓ。考试常给 S(x) 求 mₓ，用定义积分直接算。
1000题·P13中心死亡率 S(x)=(80−x)/80（0≤x≤80），求 m₂₀。
骨架：分子 = ∫₀⁶ l₂₀₊ₜμ₂₀₊ₜdt（6 年内死亡数），分母 = ∫₀⁶ l₂₀₊ₜdt（平均生存人年）→ 1/57。
展开详尽解答

μ₂₀₊ₜ=1/(60−t)，l₂₀₊ₜ=(80−20−t)/80∝(60−t)。分子 ∫₀⁶ (60−t)/(80(60−t))dt=6/80；分母 ∫₀⁶ (60−t)/80 dt=6×(60+54)/(2×80)=342/80。m₂₀=(6/80)/(342/80)=6/342=1/57（答案 C）。关键：分母是「平均生存人年」∫l dt，不是 l₂₀。

mₓ ≥ qₓ 恒成立（分母 Lₓ ≤ lₓ）；UDD 下 mₓ = qₓ/(1−qₓ/2)。

1000题·P13附加死力（选择效应） 国内 55→56 死亡概率 0.005；定居国外因环境不适附加死力 μₜ=0.03−0.03t（年初 0.03 均匀递减至年末 0）。求定居国外活到 56 岁的概率与「一半国内一半国外」的混合生存概率。
骨架：p₅₅=0.995（国内）；国外 p₅₅=0.995×e−0.015≈0.9802；混合 0.5×(0.995+0.9802)=0.9876。
展开详尽解答

国外：基础死力 + 附加死力积分 ∫₀¹(0.03−0.03t)dt=0.015 → p₅₅=(1−0.005)×e−0.015=0.995×0.9851=0.9802。混合：0.5×(0.995+0.9802)=0.9876（答案 D）。

考点双重：① 附加死力对时间积分（均匀递减取均值 0.015）；② 选择效应是生命表「选择表 vs 终极表」的连续版——承保选择期后死亡率逐渐回归终极水平。

选择表 · 终极表 · 综合表（概念三连）：选择表按「投保后经过年数（选择期）」分层，刚承保（freshly underwritten）死亡率最低；终极表是选择效应耗尽后的 x 岁死亡率；综合表不区分选择效应、全人群混合。简答考「为什么保险公司用选择表定价」——刚承保人群经核保筛选，死亡率显著低于终极水平，用综合表会高估风险、定价偏高失竞争力。
