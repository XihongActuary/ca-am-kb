T1「掌握精算模型的基本理论和方法，能够对损失风险和经营风险进行定量分析」

这句话对应风险理论 30%（ch1）。拆三层：原理——概率分布刻画随机性；方法——复合分布与聚合近似；应用——定价、准备金、偿付能力。

原理层：随机性怎么进入保险

保险的两大随机源：频率 N（赔几件）与强度 X（单件赔多少）→ 总损失 S = X₁+…+XN（复合分布）。
矩公式（一切计算的起点）：E(S)=λE(X)；Var(S)=λE(X²)（复合泊松）——强度的二阶矩直接进方差，这是易错第一名。

方法层：三把尺子

场景方法考点锚点
小组合、要精确分布卷积 / Panjer 递推ch1 §1.3
大组合、要近似正态近似 / 平移伽马近似ch1 §1.4
多期经营、问生存破产模型与调节系数ch1 §1.5
要资本与风险度量VaR / TVaR（ch1 §1.7）偿付能力应用

应用层：损失风险 vs 经营风险（对照表在 ch1 §1.7）

一句话分清：损失风险问「赔款会波动多少」；经营风险问「波动的赔款撞上有限的保费和资本，公司还安全吗」。前者是分布问题，后者是资本问题——用 VaR/TVaR 把分布翻译成资本要求，就是「定量分析经营风险」的全部动作。

简答模板 「如何对某产品线进行经营风险定量分析？」按三级火箭答：① 拟合频率/强度分布，得总损失分布；② 算 VaR/TVaR，与「保费+准备金+资本」比较得资本缺口；③ 用再保险/定价附加/资产调整弥合缺口，并做压力测试验证极端情景。

T2「掌握生存模型理论、生命表基础知识及生存函数的估计，了解生命表编制原理」

对应 生存分析 15%（ch2）+ model.html §5 修匀。考纲用词很有层次：掌握理论 → 掌握基础与估计 → 了解编制，深度递减、 breadth 递增。

生存模型理论：三个函数一条链

S(t)（还能活过 t 的概率）、f(t)（密度）、μ(t)（瞬时死力）互相唯一确定：
f(t)=−S′(t)；μ(t)=f(t)/S(t)=−d ln S(t)/dt；S(t)=exp{−∫₀ᵗ μ(s)ds}。
还有整数年龄上的表函数：lₓ、dₓ、qₓ、pₓ、mₓ（中心死亡率，ch2 §2.5）、eₓ（完整/ curtate 期望）。

生存函数的估计：三族方法

族方法适用要害
非参数Kaplan–Meier 乘积极限小样本、有删失Ŝ(t)=Π(1−dᵢ/nᵢ)；风险数剔除此前死亡与删失
非参数Nelson–Aalen 累积风险同上Ĥ=Σsᵢ/rᵢ；Ŝ=e^(−Ĥ)；置信区间用对数变换
参数指数/威布尔/冈珀茨 MLE要外推与解释删失处似然贡献是 1−F(c)（生存概率）

生命表基础知识 + 编制原理（ch2 §2.5 有五步流水线详解）

基础：分数年龄假设（UDD/常死力/Balducci，ch2 §2.2）、选择-终极表结构、多重减因与联合生存。编制：数据 → 暴露数 → 估计 → 修匀 → 补尾。「了解」级考点用名词解释准备：如「什么是中心死亡率」「为什么高龄段要外推」。

记忆口诀：「S 管生存，μ 管瞬时，f 管密度；数据进表先数人年，估完还要磨光滑」——理论链 + 编制流水线各记一句。

T3「掌握随机模拟、回归分析、时间序列的基础原理、方法和应用」

对应 ch3（10%）+ ch4（15%）+ ch5（10%），合计 35%——比风险理论还多，但单章权重低，考法是「基础原理 + 识别 + 简单计算」，不像风险理论那样深挖。三个板块共用一句方法论：模型设定 → 估计 → 检验 → 应用。
板块基础原理（一句话）核心方法保险应用
随机模拟大数定律 + CLT 兜底，误差 O(1/√n)逆变换、Box–Muller、复合分布两步法、Bootstrap、MCMC复合损失分布、准备金区间、风险度量模拟
回归分析条件期望的函数化；BLUE（高斯–马尔可夫）OLS、假设检验、GLM（指数族+连接函数）、Ridge/Lasso定价因子分析、频率/强度 GLM、费用驱动
时间序列平稳性（Wold 分解）+ ARMA 两大族ADF 检验、ACF/PACF 识别、ARIMA、协整与误差修正赔付通胀、投资收益、保费增长预测
「基础原理」怎么考：① 概念题——「为什么模拟误差是 O(1/√n)」「OLS 何时最优」「什么叫平稳」；② 识别题——ACF/PACF 形状配 AR/MA；③ 计算题——逆变换一步、AR(1) 平稳条件 |φ|<1、回归系数解读。每个板块把「原理一句话 + 方法清单 + 一个算例」绑着记，不要孤立背名词。

T4「了解机器学习的基本原理，具备对数据进行分析的能力」

对应 机器学习 20%（ch6）。「了解」≠不考——冲刺课明确此章以概念辨析为主；「具备数据分析能力」则要求你能写出完整分析流程（ch6 §6.2 有七步骨架）。

基本原理：三个关键词

① 统计学习三要素：模型（假设空间）+ 策略（经验/结构风险最小化）+ 算法（求解）；
② 偏差–方差权衡：泛化误差 = 偏差² + 方差 + 噪声，复杂度 U 形——「了解原理」考的就是它；
③ 泛化：训练误差 ≠ 测试误差，交叉验证是唯一的诚实评估。

数据分析能力：保险场景四件套

场景任务类型候选方法
续保率 / 退保预测监督 · 分类Logistic 回归、决策树、随机森林
客户分群与交叉销售无监督 · 聚类K-means、层次聚类
理赔欺诈识别监督 · 分类（不平衡）GLM 基线 + 集成方法，看 AUC/召回率
高维指标压缩无监督 · 降维PCA（先标准化）
易错辨析（冲刺课重点）：PCA 之前必须标准化；K-means 的 K 用肘部法/轮廓系数定，不是拍脑袋；「不平衡样本准确率 99%」可能是全预测为负类——要看混淆矩阵；监督 vs 无监督的分界是「有没有标签 y」。
