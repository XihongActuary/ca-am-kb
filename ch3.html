3.1随机数 中频★★

模拟的原料是 U(0,1) 均匀随机数。产生方法三选一：查表法、物理法、数学方法（考试核心）。

① 线性同余法

一阶：Wn = (k·Wn−1 + I) mod m，　Un = Wn/m　（k, m 取定）
二阶：Wn = (k₁Wn−1 + k₂Wn−2 + I) mod m，依次类推高阶
教B4第13章。同余法产生的是伪随机数：周期有限、可复现。易错：mod 运算先于除法；U 落在 [0,1)。
随机模拟的原理基石（简答「基本原理」就用这三句）：① 逆变换定理——若 U~U(0,1) 且 F 连续严格增，则 X=F⁻¹(U) 的分布恰为 F（证明：P(X≤x)=P(F⁻¹(U)≤x)=P(U≤F(x))=F(x)）；② 大数定律——独立重复模拟的样本均值依概率收敛到期望，所以「模拟 → 求平均」就是对期望的合法估计；③ 中心极限定理——估计误差 √Var(X)/n 量级，蒙特卡洛误差按 O(1/√n) 收缩：精度提高一位小数要 100 倍样本，所以先想方差缩减（对偶变量、控制变量、分层抽样、重要性抽样），再想加机器。

② 反函数法（逆变换法）

连续型：① 求 F(x)=u 的反解 x=F−1(u)；② 抽 u∼U(0,1)，令 x=F−1(u)
离散型：P(X=ai)=pi，若 Σj=0i−1pj ≤ u < Σj=0ipj，则 X=ai
原理：U=F(X) 服从 U(0,1)。指数分布：X=−(1/λ)ln(1−u) 或 −(1/λ)ln(u)。

③ 复合型随机变量模拟

S=ΣXi，N∼P(λ)：先产生泊松随机数 n₁，再生成 n₁ 个 X 的随机数相加；或用 Panjer/直接法生成。题冲刺考点

④ Box-Muller 变换

X₁ = (−2ln U₁)½·cos(2πU₂)，　X₂ = (−2ln U₁)½·sin(2πU₂)
U₁,U₂ 独立同 U(0,1) ⇒ X₁,X₂ 独立且服从标准正态 N(0,1)。一次消耗两个均匀数、产出两个正态数。反向考法：给 X₁ 反解所需 U₂。
冲刺例（对数正态变换） 已用 Box-Muller 方法产生标准正态随机数 0.8082。现需随机数 Y=√X，其中 X 服从对数正态分布 μ=5、σ²=4。求得到的随机数。
骨架：① lnY = lnX/2 ∼ N(2.5, 1)；② Y=e2.5+Z，Z=0.8082；③ Y=e3.3082≈27.34。
展开详尽解答

X∼LN(5,4) ⇒ lnX∼N(5,4) ⇒ lnY=½lnX∼N(2.5, 1)。

标准正态随机数 Z=0.8082 对应 lnY=2.5+0.8082=3.3082，故 Y=e3.3082≈27.34。

点评：对数正态链条「取对数变正态、平方根折半参数」是随机模拟与分布变换的双料高频点。

X₂=√(−2lnU₁)·sin(2πU₂) —
正解算例：U₂=0.3725 时 X₁=0.8082（冲刺例题的逆过程）。

3.2模拟样本的容量 低频★

模拟精度靠大数定律与中心极限定理兜底：样本均值的标准误按 1/√n 收缩。
P(|X̄n − μ| < ε) ≥ 1 − α　⇒　n ≥ ( zα/2·σ / ε )²
σ 未知时用样本标准差 s 替代。误差减半，样本量翻四倍——「√n 代价」是简答题的标准答案点。

3.3Bootstrap 模拟 中频★★

手头只有一份样本，想知道估计量的波动？——对样本本身反复重抽样。
  • 非参数 Bootstrap：从原始样本有放回抽取等容量新样本，重复 B 次，每次计算统计量 θ̂*，用 θ̂* 的经验分布估计 θ̂ 的标准误与置信区间。
  • 参数 Bootstrap：先拟合参数分布，再从拟合分布抽样，步骤相同。
  • 典型用途：估计统计量的标准误、构造置信区间（百分位法）、评估模型稳定性。
概念辨析（简答题常客）：Bootstrap 的对象是样本（数据），不需要知道总体分布；蒙特卡洛模拟的对象是已知分布的随机变量。两者都靠重复，但原料不同。

3.4MCMC 模拟 中频★★

要从一个难抽样的复杂后验分布取样？——造一条马尔可夫链，让它的平稳分布就是目标分布。
  • 思想：构造转移核的马尔可夫链 {Xn}，使其平稳分布 π = 目标分布 f；链跑够久后样本近似来自 f。
  • Metropolis-Hastings：从建议分布 q(y|x) 提议新点，按接受率 α=min{1, [f(y)q(x|y)]/[f(x)q(y|x)]} 接受/拒绝，保证细致平衡。
  • Gibbs 抽样：多元分布下逐条件分布轮换抽样，接受率恒为 1。
  • 实操概念：burn-in（预烧期样本丢弃）、混合速度、自相关与 thinning。
记忆口诀：「同余造均匀，反函数配分布，Box-Muller 生正态，Bootstrap 抽自己，MCMC 走链子」——五个名词一句话装下，概念辨析题直接落笔。

3.5题库精粹 题逐题吸收

取自《A3过关必做1000题》第 13 章「随机模拟」（书页号已标注）——本章考点就这四板斧：逆变换、离散查表、Box-Muller、分布间变换。
1000题·P319Box-Muller 数值代入 u₁=0.6341、u₂=0.5791，用 Box-Muller 生成标准正态随机数 X₁、X₂。
骨架：R=√(−2ln 0.6341)=0.9545；X₁=R·cos(2πu₂)=0.9545×cos(208.5°)=−0.8399；X₂=R·sin(2πu₂)=−0.4536。答案 D。
展开详尽解答

X₁=√(−2ln u₁)·cos(2πu₂)，X₂=√(−2ln u₁)·sin(2πu₂)。

−2ln 0.6341=0.9112，√=0.9545；2π×0.5791=3.6388 rad=208.5°，cos=−0.8799，sin=−0.4752。

X₁=0.9545×(−0.8799)=−0.8399；X₂=0.9545×(−0.4752)=−0.4536。

两件事必对：半径只由 u₁ 决定，角度只由 u₂ 决定；cos/sin 一正一负配对出现。考试给候选答案时先算符号再算数值。

1000题·P319离散逆变换（负二项） 负二项分布 k=6、p=0.6，取 u₁=0.345、u₂=0.789。用逆变换法求对应随机数。
骨架：查累积分布：P(N≤3)=0.4827、P(N≤7)=0.7536、P(N≤8)=0.8419。u₁=0.345∈(0.316,0.483]→3；u₂=0.789∈(0.754,0.842]→6。答案 B (3,6)。
展开详尽解答

离散逆变换：找最小的 n 使 P(N≤n)≥u。

u₁=0.345：P(N≤2)=0.3155<0.345≤P(N≤3)=0.4827 → n=3。u₂=0.789：P(N≤5)=0.7536<0.789≤P(N≤6)=0.8419 → n=6。

答案 B (3,6)。

口诀：累积概率第一个盖过 u 的 n 就是答案——区间左开右闭，边界值归上层。

1000题·P319指数分布逆变换 寿命~指数（均值 1000 小时），取 u=0.2487。求模拟寿命。
骨架：x=−1000·ln(0.2487)=1000×1.392=1392 小时。答案 C。
展开详尽解答

F(x)=1−e−x/1000=u ⇒ x=−1000·ln(1−u)。

题库用 x=−1000·ln(u)（把 u 当作 1−u，同为均匀分布等价）：−ln 0.2487=1.3916 → x≈1392。

1−u 与 u 都是 U[0,1]——两种写法都对，但同一题内要一致；给出具体 u 值时按题目的约定算。

1000题·P319正态→对数正态链 生成 N(5.0, 2.0²) 随机数得 6.40 与 1.98。求对应对数正态随机数。
骨架：直接取指数：e6.40≈601.85、e1.98≈7.24。
展开详尽解答

若 Y=eX、X~N(μ,σ²)，则 Y~对数正态。模拟时先造正态数再取指数即可——不需要重新做 Box-Muller。

链式生成思想：均匀→正态→对数正态（或→其他变换），一条流水线，每一环都可能是考点。
