第一部分基础：术语、评估与度量

西瓜书前两章。这一部分的概念辨析是科目四机器学习板块最直接的命题点——不考推导，考「分得清」。

ML1绪论：术语一网打尽 高频★★★

Mitchell 形式化定义：设 P = 程序在任务类 T 上的性能，E = 经验（历史数据集）。若程序利用经验 E 在任务 T 上使性能 P 得到改善，则称该程序对 E 进行了学习。
术语含义易混点
数据集 / 样本所有记录的集合 / 每一条记录（instance、example）统计学家叫「观测/变量」，数据库叫「记录/字段」，机器学习叫「样本/属性」——同一件事三种叫法
特征向量 / 维数一个样本在坐标轴上的点 / 特征个数维数极大即「维数灾难」，是第 11 章降维的出发点
训练集 / 测试集用于学习的样本集 / 用于检验的样本集二者必须互斥，否则评估过于乐观
泛化能力模型适用于新样本的能力，即从特殊到一般学习的目标不是训练误差小，而是泛化误差小
分类 / 回归预测离散值 / 预测连续值—
监督 / 无监督训练数据有标记 / 无标记聚类、关联规则属无监督；分类、回归属监督
考点视角：常以选择题形式给出一句话描述，让你判断属于哪个术语（尤其「泛化能力」「监督/无监督」「维数灾难」）。记住判定链条：有没有标记 → 监督还是无监督；预测值离散还是连续 → 分类还是回归。

ML2模型的评估方法：三种划分 高频★★★

留出法：D = S ∪ T，S ∩ T = ∅；常见 2/3 ~ 4/5 用于训练。要分层抽样保持分布一致；单次划分不稳定，应多次随机划分取平均。
k 折交叉验证：D 分为 k 个大小相同的互斥子集，每次取 k−1 个训练、余下 1 个测试，返回 k 次均值。常用 k=10；k=m（每折 1 个样本）即留一法——评估准确但计算量巨大。
自助法（bootstrap）：m 次有放回采样得 D′，样本始终不被采到的概率 → e−1 ≈ 36.8%，故 D′ 训练、(D−D′) 测试。适合小数据集；缺点是改变了初始分布、引入估计偏差。
口诀：留出「一次分两半」、交叉「轮流当测试」、自助「有放回，三成六」。数据集够大用前两种，数据小才用自助。
⚠ 易错：自助法那个 36.8% 是 极限值（(1−1/m)m → e−1），不是精确等于；选择题里出现「约 36.8%」才是对的。另外调参完成后，要用完整数据集 D 重新训练一次——这点常被忽略。
考点视角：命题形式多为「下列关于评估方法的说法，正确的是」——重点测：① 留出法需分层抽样；② k 折常用 10 折；③ 留一法准确但开销大；④ 自助法改变了数据分布。四个说法能分辨即可。

ML3性能度量：从准确率到 AUC 高频★★★

回归：均方误差 MSE = (1/m)Σ(f(xi) − yi)2。
分类：错误率 E = 分错样本数 / 总数；精度 Acc = 1 − E。
查准率 P = TP/(TP+FP)（推出来的里面有多少是对的）；查全率 R = TP/(TP+FN)（该推出来的推出来了多少）。
F1 = 2PR/(P+R)（调和平均）；更一般地 Fβ = (1+β2)PR/(β2P + R)，β>1 偏重查全、β<1 偏重查准。
⚠ FN 与 FP 别搞反：FN 是「真的为正、被判成负」（漏报），FP 是「真的为负、被判成正」（误报）。按字面 False→Negative 去理解会正好反掉。保险语境记忆：欺诈识别里 FN 是「真欺诈没抓到」（赔钱），FP 是「好客户被误判」（伤体验）——前者代价通常更高，所以要看代价敏感。
ROC：横轴 FPR = FP/(FP+TN)，纵轴 TPR = R = TP/(TP+FN)。AUC = ROC 曲线下面积，衡量排序质量：AUC=1 表示所有正例排在负例之前，0.5 表示随机。
P-R 曲线：查全率为横轴、查准率为纵轴；曲线被完全包住则对方更优，交叉时看平衡点 BEP（P=R 处取值）。
图一 · P-R 曲线与 ROC 曲线对照：P-R 关注「查得准/查得全」，ROC 关注「排序质量」；类别极不平衡时 P-R 更能暴露问题。
代价敏感错误率：cost01（正判成负）与 cost10（负判成正）不相等时，最小化总体代价而非错误率；对应「代价曲线」，横轴为正例概率代价、纵轴为归一化代价，ROC 上每点对应一条线段，取下界围成的面积即期望总体代价。
考点视角：三件事必考——① P/R/F1 的定义与相互制约（P 高则 R 低）；② AUC 的含义（排序质量、0.5 为随机）；③ 类别不平衡时准确率失效（正例 99% 时全猜正也有 99% 准确率）。保险应用：理赔欺诈识别正例极少，必须看 P-R 而不是准确率。

ML4比较检验与偏差-方差 中频★★

假设检验：用测试错误率推测泛化错误率的分布（二项检验 / t 检验）。
交叉验证 t 检验：两学习器在相同折上成对比较差值。
McNemar 检验：二分类专用，若性能相同则 e01 = e10，统计量 (|e01−e10|−1)2/(e01+e10) ~ χ2(1)。
Friedman 检验：多数据集多算法排序（赋序值 1,2,…），超出临界值则拒绝「性能相同」，再用 Nemenyi 后续检验两两比较（看平均序值差是否超过临界值域 CD）。
偏差-方差分解：期望泛化误差 = 偏差2 + 方差 + 噪声。
偏差 = 预测期望与真实值的偏离，刻画拟合能力；方差 = 每次预测相对预测期望的离散，刻画稳定性。
图二 · 偏差-方差窘境：训练不足时偏差主导（欠拟合），训练过度时方差主导（过拟合）。集成学习中 Boosting 主要降偏差、Bagging 主要降方差，正对应这张图的两端。
口诀：欠拟合——训练误差和测试误差都大，偏差主导；过拟合——训练误差极小而测试误差变大，方差主导。过拟合是机器学习的关键障碍，没有彻底的解决方案，只能缓解（正则化、剪枝、早停、增数据）。
考点视角：简答题常问「什么是过拟合，如何缓解」，按四招作答：正则化 / 早停 / 剪枝 / 增加数据或数据增强，再补一句「过拟合无法彻底避免」。

第二部分监督学习：六大模型

从最简单的线性回归，到曾经取代过神经网络的 SVM。这一部分是「原理 + 方法」的主战场。

ML5线性模型：回归 · 对数几率 · LDA 高频★★★

一元线性回归：最小化均方误差，对 w、b 求偏导置零 → 最小二乘解。
多元：ŷ = wTx + b，矩阵形式 ŵ* = (XTX)−1XTy（仅当 XTX 满秩可逆；否则需正则化）。
广义线性模型：y = g−1(wTx + b)，g(·) 为联系函数；取 g = ln 即得对数线性回归。
对数几率回归（Logistic）：y = 1/(1 + e−(wTx+b))，把线性回归的预测值压到 (0,1)；等价于用线性模型逼近真实标记的对数几率 ln[y/(1−y)]。参数由极大似然估计（不是最小二乘）。
LDA 线性判别分析：把样本投影到一条直线，使同类投影尽可能近、异类投影尽可能远；最大化「广义瑞利商」= 类间散度 / 类内散度。LDA 用到类别标记，因此也是一种监督降维技术（可降到 N−1 维，N 为类别数）。
多分类拆分：OvO（N(N−1)/2 个二分类器，投票）、OvR（N 个，一对其余）、MvM（若干正类 vs 若干反类，常用 ECOC 编码，按海明/欧氏距离解码）。
类别不平衡三招：欠采样（EasyEnsemble）、过采样（SMOTE 插值）、再缩放（阈值移动，也是代价敏感学习的基础）。
考点视角：① Logistic 与线性回归的区别（前者分类 + 极大似然，后者回归 + 最小二乘；前者输出经 Sigmoid 压缩到 (0,1)）；② LDA 与 PCA 的区别（LDA 用标记、监督降维、最多 N−1 维；PCA 不用标记、无监督、维数自选）。这两组对比是高频辨析题。

ML6决策树：ID3 / C4.5 / CART 高频★★★

信息熵：Ent(D) = −Σk pk log2 pk（值越小越纯）。
信息增益（ID3）：Gain(D, a) = Ent(D) − Σv |Dv|/|D| · Ent(Dv)，取最大者划分。
增益率（C4.5）：Gain_ratio = Gain(D,a) / IV(a)，其中 IV(a) = −Σv |Dv|/|D| · log2(|Dv|/|D|)（属性 a 的固有值，取值越多越大）。C4.5 先筛出高于平均的候选，再从中选增益率最大的。
基尼指数（CART）：Gini(D) = 1 − Σk pk2，反映「随机抽两个样本类别不一致的概率」，越小越纯。
⚠ ID3 的坑：信息增益偏向取值数目多的属性——极端情况「编号」属性会把每个样本单独分一支，熵为 0 却毫无用处。这正是 C4.5 引入增益率的原因。
连续值：二分法——排序后取相邻均值作为候选切点（n−1 个），选信息增益最大的切点。
缺失值：① 仅在无缺失的子集上算信息增益，再乘以该子集占比；② 缺失样本按各分支样本比例作为权重同时划入所有分支。
剪枝：预剪枝（生成时评估，不提升就不分支——省时间但有欠拟合风险）、后剪枝（生成完整树后自底向上考察——开销大但泛化通常更好）。
口诀：ID3 看增益、C4.5 看增益率、CART 看基尼；连续值用二分、缺失值用权重；预剪枝贪心、后剪枝更准。
考点视角：必考三选一式的对应（算法 ↔ 划分准则），以及剪枝的两种策略对比。可能会给一个小数据集让你算熵或信息增益——本站 CH.06 有「熵与基尼指数」演算器可练手。

ML7神经网络：从 M-P 到 BP 中频★★

M-P 神经元：接收 n 个带权输入 → 求加权和 → 减去阈值 → 经激活函数输出。理想激活是阶跃函数，但不连续不光滑，实际常用 Sigmoid（把输入挤到 (0,1)，又称挤压函数）。
感知机：两层神经元，仅输出层是功能神经元；权重更新 Δwi = η(y − ŷ)xi（η∈(0,1) 为学习率）。只有一层功能神经元 ⇒ 只能处理线性可分（异或问题解不了）。
多层前馈网络：每层与下一层全互连、无同层连接、无跨层连接；「前馈」指拓扑上无环，不等于不能反向传播。
BP 算法：误差逆传播 + 梯度下降，以单个样本的均方误差之负梯度调节连接权与阈值；标准 BP 每次针对单个样本更新，累积 BP 读完全部数据才更新一轮（数据量大时标准 BP 往往更好）。
缓解过拟合：早停（训练集误差降而验证集误差升时停止）+ 正则化（误差函数中加入权值平方和项，λ 折中拟合与复杂度）。
局部最小 vs 全局最小：梯度为 0 即局部极小；跳出手段——多组不同初值初始化取最优、模拟退火、随机梯度下降。
深度学习：增加隐层数比增加每层神经元更有效；多隐层难训的两条路——无监督逐层预训练 + 微调（如 DBN）、权共享（如 CNN）。本质上是表示学习/特征学习，把人工特征工程自动化。
考点视角：① 感知机只能解线性可分、XOR 需多层；② 激活函数为何不用阶跃（不连续、不可导）；③ 早停与正则化的作用；④ 深度学习 = 自动特征工程。以概念题为主，不考反向传播的矩阵推导。

ML8支持向量机：间隔、对偶与核 中频★★

函数间隔 = ŷ(wTx + b) = |wTx + b|（会随 w、b 同比例缩放而变，故不能用来最大化）；几何间隔 = ŷ(wTx + b)/‖w‖，即点到超平面的真实距离。
基本型：令几何间隔为 1，则最大化间隔 ⇔ 最小化 ½‖w‖2，约束 yi(wTxi + b) ≥ 1 —— 一个凸二次规划问题。
满足 y(wTx+b) = 1 的样本即支持向量；非支持向量对应的拉格朗日乘子 αi = 0，因此预测时只需与支持向量求内积。
为何转对偶：① 更易求解；② 自然出现内积形式，从而引出核函数。对偶问题：max Σαi − ½ΣΣαiαjyiyjxiTxj，s.t. Σαiyi = 0，αi ≥ 0；由 SMO 求解。
核函数：κ(xi, xj) = ⟨φ(xi), φ(xj)⟩，直接算出高维空间中的内积而不必显式写出映射——「低维计算，高维表现」。常用：线性核、多项式核、高斯（RBF）核、Sigmoid 核。核函数选择是 SVM 最大的变数。
软间隔：允许少量样本不满足约束，引入松弛变量 ξi 与 hinge 损失；目标 ½‖w‖2 + C·Σξi。对偶形式与硬间隔完全相同，只是 α 多了上限 C。C 越大越不容忍犯错（趋向硬间隔、易过拟合），C 越小越宽容。
口诀：函数间隔会缩放、几何间隔才是真距离；支持向量定边界、非支持向量 α 全为零；核函数低维算高维；C 大不容错、C 小更宽容。
考点视角：常考三点——① 支持向量的定义与「只与支持向量有关」；② 核函数的作用（避免显式高维映射、解决线性不可分）；③ 软间隔与 C 的含义。公式推导一般不要求。

ML9贝叶斯分类器与 EM 算法 中频★★

贝叶斯判定准则：最小化条件风险 R(c|x) = Σ λij P(cj|x)；取 0-1 损失时退化为「选后验概率最大的类」。
生成式 vs 判别式：生成式先对联合分布 P(x,c) 建模再求 P(c|x)（贝叶斯、高斯混合）；判别式直接对 P(c|x) 建模（决策树、神经网络、SVM）。
朴素贝叶斯：假设属性条件独立，P(c|x) ∝ P(c)·Πi P(xi|c)。MLE 四步：写似然 → 取对数 → 求偏导置零 → 解似然方程组。
拉普拉斯修正：P̂(c) = (|Dc|+1)/(|D|+N)，P̂(xi|c) = (|Dc,xi|+1)/(|Dc|+Ni)，避免某个属性值未出现导致概率被抹成 0。
EM 算法：存在隐变量时的参数估计利器。E 步——固定 θ，求隐变量 Z 的期望（实为后验概率，建立对数似然的下界）；M 步——固定 Q，最大化下界更新 θ。用 Jensen 不等式把「和的对数」变成「对数的和」。
可视为一种坐标下降：一次固定一个变量、对另一个求极值，交替直到收敛。
与本站 CH.03 随机模拟的联系：EM 的思路与 Gibbs 采样、MCMC 同属「隐变量/高维积分难求时的迭代策略」，只是 EM 求的是点估计（极大似然），MCMC 求的是分布。K-Means 其实也是 EM：类别=隐变量、类中心=参数。
考点视角：① 先验概率 vs 后验概率；② 为何要拉普拉斯修正；③ EM 两步各做什么（E 步求期望/下界，M 步极大化）。「K-Means 是 EM 的特例」是很好的简答加分句。

第三部分集成学习与无监督学习

「三个臭皮匠」的数学（集成），以及没有标准答案时怎么找结构（聚类、降维）。

ML10集成学习：好而不同 高频★★★

核心矛盾：集成要有效，个体学习器必须「好而不同」——准确性与多样性不可兼得。
若基分类器独立且错误率均为 ε，集成错误率 = Σk>T/2 C(T,k) εk(1−ε)T−k，随 T 指数下降；但现实中独立性不可能成立，故只能尽量制造差异。
Boosting / AdaBoost：串行生成，不断加大上一轮分错样本的权重，最后按误差率加权组合（误差率小的权重大）。使用指数损失函数；只适用于二分类（标准版）。主要降低偏差。
Bagging：并行生成，用自助采样（约 36.8% 样本未被采到）造出 T 个不同训练集。主要降低方差，适合不稳定学习器（决策树、神经网络）。
随机森林：Bagging + 属性扰动（每个节点从随机 K 个属性中选最优划分，推荐 K = log2d）。多样性来自样本扰动 + 属性扰动。
结合策略：平均法（回归；性能相近用简单平均，相差大用加权平均）、投票法（分类；绝对多数/相对多数/加权，绝对多数提供拒绝选项）、学习法（Stacking：用基学习器输出训练一个次级学习器，输入用类概率、次级用 MLR 效果较好）。
增强多样性的四种扰动：数据样本扰动、输入属性扰动、输出表示扰动、算法参数扰动。
口诀：AdaBoost 串行降偏差、Bagging 并行降方差、随机森林在 Bagging 之上再加属性扰动。看到「降低方差」选 Bagging/随机森林，看到「降低偏差」选 Boosting。
考点视角：这是机器学习板块最常考的对比题：Boosting vs Bagging（串行/并行、样本权重/自助采样、降偏差/降方差）。再记一句：随机森林基学习器固定为决策树，且训练效率高于 Bagging 版决策树（因为只在属性子集中选划分）。

ML11聚类：距离、原型、密度、层次 高频★★★

距离度量：闵可夫斯基距离 dist = (Σ|xi−xj|p)1/p；p=1 曼哈顿、p=2 欧氏、p→∞ 切比雪夫。有序属性（连续 + 有序离散）可直接算；无序属性用 VDM：VDMp(a,b) = Σk |mk,a/ma − mk,b/mb|p。
性能度量：外部指标（与参考模型比：Jaccard、FM、Rand 指数，基于 a/b/c/d 四量）、内部指标（不看外部：DB 指数——越小越好，Dunn 指数——越大越好）。直观标准：簇内高内聚、簇间低耦合。
K-Means：随机定类中心 → 按距离划簇 → 重算类中心 → 迭代至收敛；最小化平方误差 E = Σi ‖xi − μλi‖2。本质是 EM（类别=隐变量）。
LVQ：用真实类标辅助聚类——分对了原型向量靠近样本，分错了远离。
高斯混合聚类：每个簇是一个多维高斯分布，用 EM 估计 α、μ、Σ，按后验 γji 划分（软聚类）。
DBSCAN（密度聚类）：核心对象 / 密度直达 / 密度可达 / 密度相连；找出核心对象所有密度可达的样本成簇。不需要预先指定 k，能发现任意形状簇、能识别噪声点；对参数（邻域半径 ε、MinPts）敏感。
AGNES（层次聚类）：自底向上，每次合并最近的两类；类间距离有三种——单链接（最小距离，包容）、全链接（最大距离，严格）、均链接（平均距离，折中）。

ML12降维与度量学习 中频★★

维数灾难：高维下样本稀疏、密采样所需样本数为天文数字、距离计算困难（这正是 SVM 要用核函数的原因）。降维即把高维空间嵌入合适的低维子空间（低维嵌入）。
kNN：无显式训练过程的惰性学习（训练开销为零，预测时才计算）；k 太小受噪声干扰（k=1 最极端），k 太大预测能力退化（k=m 时全猜一类），通常用交叉验证选 k。它常被用来为降维算法挑选低维维数。
MDS 多维缩放：要求降维前后样本间距离保持不变；由距离矩阵 D 求内积矩阵 B（中心化后 B = ZTZ），再做特征值分解得到低维坐标 Z。
PCA 主成分分析：线性变换投影到超平面，要求最近重构性（点到超平面距离近）与最大可分性（投影点尽量分散）——两条思路导出的优化问题完全相同；对协方差矩阵做特征值分解，取前 d′ 个大特征值对应的特征向量。
KPCA：先映射到高维再线性降维；利用「空间中任一向量可由所有样本线性表出」，最终只需对核矩阵 K 做特征分解。
流形学习：Isomap（保持邻域内距离，用测地线距离 + MDS）、LLE（保持邻域内线性关系）。近邻图构建的两难：邻域过大「短路」、过小「断路」。
马氏距离：dist2 = (xi−xj)T M (xi−xj)；标准马氏距离中 M = Σ−1（协方差矩阵的逆），考虑属性相关性且尺度无关。度量学习就是学习这个度量矩阵 M（须为半正定对称）。

ML13特征选择与稀疏学习 低频★

三种范式：过滤式（先选特征再训练；Relief 用「相关统计量」——猜中近邻 near-hit 越近越好、猜错近邻 near-miss 越远越好，多分类用 Relief-F）、包裹式（把学习器当评价准则，LVW 随机搜索 + 停止参数 T，开销大）、嵌入式（选择与训练融合，靠 L1 正则）。
L1 vs L2：L1（Lasso）使部分权重精确为 0 ⇒ 特征选择；L2（Ridge）使权重趋于 0 但不为 0 ⇒ 控过拟合。原因：L1 在 0 附近下降速度快（绝对值 vs 二次函数），且约束区域是菱形、更容易在顶点处与等高线相切得到稀疏解。
子集搜索：前向（逐步加）、后向（逐步减）、双向（加减并行）；评价可用信息增益。
口诀：过滤式快而粗、包裹式准而慢、嵌入式靠 L1。要「把没用的特征踢掉」用 L1，要「把权重压小防过拟合」用 L2。
考点视角：L1 与 L2 的区别是唯一高频点，务必说清「L1 稀疏、可做特征选择；L2 平滑、防过拟合」。与本站 CH.04 回归分析的 Ridge/Lasso 部分是同一知识的两个视角，可对照着看。

ML14计算学习理论：PAC 与 VC 维 低频★

基本概念：目标概念 c（理想映射）、假设空间（算法所有可能映射的集合）、可分/一致（假设空间包含目标概念）。
PAC（概率近似正确）：以置信度 1−δ 学得泛化误差 ≤ ε 的假设。加上样本数要求 → PAC 可学习；再加上多项式时间 → PAC 学习算法。
有限假设空间：可分情形下，剔除经验误差不为 0 的假设，所需样本数 m ≥ (1/ε)(ln|H| + ln(1/δ))；不可分（不可知学习）时用 Hoeffding 不等式给出泛化误差界。
增长函数：假设空间对 m 个样本能打出的最多标记结果数；打散：能实现全部 2m 种对分。
VC 维：假设空间能打散的最大数据集大小 d（存在大小为 d 的可打散集，但不存在 d+1 的）。结论：任何 VC 维有限的假设空间都是（不可知）PAC 可学习的。
稳定性：输入变动一个样本，输出损失变化不超过 β ⇒ β-均匀稳定性；满足 ERM 且 β-均匀稳定的假设空间可学习。
考点视角：只需掌握三条定性结论：① PAC = 「大概率学得误差有界的假设」；② VC 维衡量假设空间复杂度（能打散的最大样本数）；③ VC 维有限 ⇒ 可学习。数值计算不考。

ML15半监督学习 低频★

主动学习 vs 半监督：主动学习挑不确定性高/置信度低的样本去问专家（仍需交互，本质还是监督）；半监督不与外界交互，直接利用未标记样本蕴含的分布信息（它们与有标记样本同分布）。
纯半监督：未标记数据不是待预测数据；直推学习：未标记数据就是待预测数据。
四类方法：① 生成式方法（假设高斯混合分布，EM 求解；强依赖分布假设）；② 半监督 SVM（TSVM/S3VM）（让超平面穿过低密度区域，给未标记样本伪标记并局部搜索调整）；③ 基于分歧（协同训练：多视图相容互补，各自挑置信度最高的样本给对方学）；④ 半监督聚类（必连/勿连约束，或少量带标记样本指定类中心）。
考点视角：命题点很集中——主动学习 vs 半监督的区别（是否需交互/查询）、纯半监督 vs 直推学习的区别（未标记样本是不是待预测样本）。

ML16概率图模型：HMM / MRF / CRF 中频★★

两类图：用有向边表依赖关系 → 贝叶斯网（如 HMM）；用无向边 → 马尔可夫网（如 MRF）。
HMM 隐马尔可夫模型：状态变量（隐）与观测变量（显）。两条依赖：① 观测只依赖当前状态；② 下一状态只依赖当前状态（马尔可夫性：现在决定未来，未来与过去无关）。三组参数：初始状态概率 π、状态转移概率 A、观测概率 B。
三个问题：评估（给定模型和观测序列，求序列概率 → 前向算法）、解码（求最可能的状态序列 → Viterbi 算法）、学习（只给观测序列调参 → EM 算法/Baum-Welch）。
MRF 马尔可夫随机场：团（两两有边相连的子集）、极大团；联合概率按极大团上的势函数分解：P(x) = (1/Z) ΠQ∈C ψQ(xQ)（Z 为规范化因子）。三条马尔可夫性：全局 / 局部 / 成对。
CRF 条件随机场：对条件分布 P(y|x) 建模（判别式），与 HMM（生成式）相对；链式 CRF 用两类特征函数——转移特征（相邻标注是否合理）、状态特征（观测与标注是否匹配）。
精确推断：变量消去（用乘法分配律把求和控制在局部）、信念传播（叶→根、根→叶两轮消息传递，节点边际正比于所收消息之积）。
与本站 CH.01 的呼应：马氏链在风险理论里是「状态转移 + 稳态分布」（本站统一用「常态/瞬态」表述），在 HMM 里是「隐状态序列的依赖结构」——同一个数学对象，两种用法。
考点视角：① 有向=贝叶斯网、无向=马尔可夫网；② HMM 三参数三问题（评估/解码/学习对应前向/Viterbi/EM）；③ HMM 是生成式、CRF 是判别式。

ML17强化学习 低频★

MDP 四要素：状态 X（对环境的感知）、动作 A、转移概率 P、奖赏函数 R。目标是学出策略 π（确定性 π(x)=a 或随机性 π(x,a)），使长期累积奖赏最大（T 步累积奖赏 / γ 折扣累积奖赏）。
探索-利用困境（K-摇臂赌博机）：仅探索（均分机会，估得准但不利用）、仅利用（只试当前最优，易陷局部）。折中：ε-贪心（以 ε 概率随机探索、1−ε 概率利用）、Softmax（按当前平均奖赏的 softmax 概率分配）。
有模型学习：四要素已知 → 策略评估（状态值函数 V、状态-动作值函数 Q，用 Bellman 等式递归）+ 策略改进（选当前最优动作）。策略迭代（评估与改进交替）与值迭代（先迭代出最优值函数）。
免模型学习：转移与奖赏未知 → 蒙特卡罗强化学习，靠采样轨迹估计 Q，用 ε-贪心保证多样性；同策略 vs 异策略。
AlphaGo 三模块：深度学习（拟合估值函数）+ 蒙特卡罗搜索树（采样）+ 强化学习（按反馈调整估值函数）。这是「三大件如何配合」最好的例子。
考点视角：考纲对强化学习只要求了解。掌握：四要素、探索-利用困境与 ε-贪心、V/Q 值函数的含义即可。
