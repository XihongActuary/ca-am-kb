§01考试形式与机考「坑位」

来自考生的第一手经验（大纲分析）：机考 = 单选＋简答（计算为主）＋ 一道 Excel 计算题。
机考系统三大坑：
  • 公式输入反人类：上标/分式/积分号要点选面板，慢且易错——平时就用 Excel 和手写练，别用 Word 公式编辑器模拟。
  • 系统可能崩溃或不显示：有考生现场换机器。遇到渲染异常立即举手示意监考，别自己反复刷新浪费时间。
  • Excel 题会用函数就算得快：题目本身不难，比拼的是函数熟练度——把 §02 的表过三遍。
备考策略（大纲分析）：官方 8 本参考书高度重合，以肖争艳《精算模型》第4版为主线，西瓜书对照目录看，时间序列/回归额外刷题。复习以「效率优先」，但学到的能力是长期资产——时间序列在 MIT 有公开课，量化投资也用得上。

§02Excel 函数武器库

按六大板块对号入座。格式：函数(参数)——考场直接照敲。
板块函数用途
通用分布EXP(x) / LN(x) / POWER(x,n)泊松 e−λ、对数正态变换、指数危险率
FACT(n) / COMBIN(n,k)阶乘与组合数（泊松/二项手算复核）
RAND() / RANDBETWEEN(a,b)均匀随机数——反函数法、Box-Muller 演示
SUMPRODUCT(range1,range2)加权矩计算：E(X²)、协方差
风险理论POISSON.DIST(n, λ, TRUE/FALSE)泊松概率与累计概率（复合/非齐次直接用）
BINOM.DIST / NEGBINOM.DIST二项 / 负二项次数分布
NORM.S.DIST(z,TRUE) / NORM.S.INV(p)正态近似求概率 / 反解分位数（安全附加、调节系数配套）
生存分析连乘 Π(1−d/n)：手敲因子×SUMIF/COUNTIFK-M 估计：COUNTIF 算风险集，逐因子相乘
回归分析SLOPE / INTERCEPT / RSQ / CORREL一元回归四件套
LINEST(y, x, TRUE, TRUE)多元回归系数＋统计量（Ctrl+Shift+Enter 老版本）
时间序列AVERAGE / VAR.S / STDEV.S均值、样本方差（平稳性初判）
CORREL(滞后列, 原列)自相关系数 ACF：先做滞后列再 CORREL
机器学习MMULT / MINVERSE / TRANSPOSE矩阵运算：马氏链极限分布、回归正规方程
IF / COUNTIFS / LOG(x,2)混淆矩阵统计、熵计算
Box-Muller 一行版：=SQRT(-2*LN(RAND()))*COS(2*PI()*RAND())　→ 标准正态随机数
逆变换指数分布：=−LN(1−RAND())/λ。这两条写进「考场快捷卡」，Excel 题秒出。

§03简答题三套模板

题型模板
计算型简答① 写出所用公式（符号定义）② 代入数据 ③ 给出结果并回答题干问句（单位别丢）
概念辨析型① 一句话定义 A 与 B ② 列 2–3 条差异（机制/假设/用途）③ 各给一个例子
证明/推导型① 写目标（证什么）② 关键中间步骤（C–K、全期望、积分可加等）③ 结论加「证毕/故成立」
记忆口诀：「公式先行，代入跟进，落笔回题」——简答题按步给分，写对公式就有一半分。

§04时间分配与心态

  • 先易后难，单选保底：单选是得分主体，卡住 2 分钟先标记跳过。
  • Excel 题放中段做：题目不难、得分稳定，别留到最后手忙脚乱。
  • 计算器/草稿：按当次考试规定携带；机考自带虚拟计算器的先摸熟位置。
  • 崩溃预案：系统异常立即报告监考要求处理/换机，同时记下进度时间点。
考前一周动作清单：① 本库 12 页过一遍骨架答案；② 模拟卷三套限时完成；③ Excel 函数表逐条在空表里敲一遍；④ 把每章「记忆口诀」抄成一页 A4。
