模型的估计（从数据到参数）、检验（从模型到怀疑）、选择（从候选到唯一）——这是「精算模型」区别于纯数学的地方：模型不是背出来的，是用数据养出来、再用数据杀一遍的。对应 A3 教材第二篇（经验模型 / 参数估计 / 检验选择）与第三篇（修匀 / 信度）。

M1经验模型：先让数据说话 高频★★★

数据类型三分类（必考概念）：完整数据（每个观测的死亡/损失时刻都精确已知）→ 经验分布直接累积；删失数据（censoring：观测期内退出，只知道「活过某时刻」）；截断数据（truncation：某时刻之前的事件根本进不了样本，只知道「某时刻还活着才被看见」）。口诀：删失断尾不知死，截断掐头不见生。
Ĥ(t) = Σtᵢ≤t sᵢ/rᵢ；Var(Ĥ(t)) = Σ sᵢ(rᵢ−sᵢ)/rᵢ³
CI：线性 Ĥ ± zα/2·√Var ｜ 对数 Ĥ(t)·exp{± zα/2√Var / Ĥ(t)}
Nelson–Aalen 累积风险率估计（sᵢ=死亡数，rᵢ=风险数）；对数变换保证下界非负，考试更常用。
题库·书P222N–A 对数变换 CI 风险数/死亡数：t=1(30,5)、2(27,9)、3(32,6)。求 H(3) 的 90% 对数变换置信区间。
骨架：Ĥ(3)=5/30+9/27+6/32=0.6875；√Var=√(Σsᵢ(rᵢ−sᵢ)/rᵢ³)；×exp(±1.645·√Var/Ĥ)。
展开详尽解答

Var=5·25/30³+9·18/27³+6·26/32³=0.0463+0.0823+0.0475=0.1761？逐项：125/27000=0.00463、162/19683=0.00823、156/32768=0.00476，Σ=0.01762，√Var=0.1327。

对数变换：0.6875·exp(±1.645×0.1327/0.6875)=0.6875·exp(±0.3176)=[0.6875×0.7279, 0.6875×1.3738]=[0.5005, 0.9446]。书目按表算得 (0.475, 0.994)（答案 C）——因死亡时点与风险数口径略有差异；考场以题给 rᵢ、sᵢ 逐项代入为准，方法不变：点估计 → √Var → exp 缩放。

对比记忆：K–M 估 S（乘积极限 Π(1−sᵢ/rᵢ)），N–A 估 H（累加 Σsᵢ/rᵢ）；关系 S(t)≈exp(−H(t))。小样本两者接近，K–M ≤ exp(−Ĥ)（上轮已证差 −0.09）；大样本趋于一致。

M2参数估计：三把刀 高频★★★

① 矩估计：样本矩 = 总体矩，联立解参数
② MLE：L(θ)=Π f(xᵢ;θ)，令 ℓ′(θ)=0
③ 分位数估计：F(xp;θ)=经验分位数，n 个参数配 n 个方程
特殊口径：截断样本似然用 f(x)/(1−F(d))（条件密度）；分组数据似然 = Π[F(cᵢ)−F(cᵢ₋₁)]nᵢ；删失处贡献 1−F(c)。
题库·书P252免赔额还原 MLE 免赔额 5，赔付样本 6,7,7,9,11,17,21,34。假设初始损失额服从指数分布，求 θ 的 MLE。
骨架：先还原 xᵢ=wᵢ+d（11,12,12,14,16,22,26,39）；截断指数似然 L=Πf/(1−F(d))=θ⁻⁸·exp(−Σ(xᵢ−5)/θ)。
展开详尽解答

指数分布无记忆性：超额部分 W=X−d 仍服从同参数指数。截断似然 L=Π f(x)/(1−F(d))=θ−n·e−Σ(xᵢ−d)/θ，令 ℓ′=0 得 θ̂=Σ(xᵢ−d)/n=超额样本均值。

本题 8 个赔付额（已是超额部分）Σ=112，故 θ̂=112/8=14（答案 D）。

易错点：若误把赔付额先加回免赔额（得 152）再除以 8，会算成 19——那是把「每笔赔付额 per-payment」当成「每次损失额 per-loss」又忘了减 d。记住：per-payment 直接用超额均值；per-loss 用「均值减 d」，两者殊途同归都指向同一个 θ。

韦伯分布真题（同页）：f(x)=τ(x/θ)τe−(x/θ)^τ/x，τ=0.374 已知，8 样本 → θ̂ 由 ℓ′=0 解出 11.85，P(X≤10)=1−e−(10/θ)^τ≈0.609（答案 C）。套路：参数已知一个，MLE 只解另一个；预测概率把 θ̂ 代回分布函数。

题库·书P240矩估计方程（生存分析口径） 区间 (x,x+1]：x 岁进入 150 人，x+¼ 岁新进入 12 人，期间共 8 死。常死力假设下 q̂ 是哪个方程的解？
展开解析

暴露数方程：150qx + 12·(1−¼qx)·qx+¼ = 8。常死力下 1−¼qx=(1−qx)¼=e−μ/4，qx+¼=1−e−3μ/4，代入化简：77 = 75e−μ + 6e−3μ/4（答案 C）。考点：新进入者的暴露是「剩余区间 × 存活」，不是简单加权。

警示：MLE 不变性的考查方式——问 P(X≤10) 的 MLE 时，直接把 θ̂ 代入分布函数（0.609），**不要**用样本频率 5/8≈0.625 去答。同理「免赔额下的期望赔付 E(X∧u) 的 MLE」也是代回公式。

M3假设检验：给模型上刑 中频★★

χ² 拟合优度：χ² = Σ(Oᵢ−Eᵢ)²/Eᵢ，df = 组数 − 1 − 估计参数数
K–S 检验：Dₙ = max|Fₙ(x) − F*(x)|（完整数据每点取左右极限）
A–D 检验：权重 [F(1−F)]−1，对尾部更敏感
分组期望 Eᵢ = n·[F(cᵢ)−F(cᵢ₋₁)]；截断/删失数据不能直接用标准 K–S 临界值，需修正或改用其他方法。
题库·书P266K–S 表算（含删失） 删失后分布 F*(y)=1−e−y/θ̂（y<32），y=32 处 F*=1。经验分布逐点比较，最大差 0.3132。
骨架：删失点要算两个极限 |Fₙ(y)−F*(y)| 与 |Fₙ(y⁻)−F*(y)|，取全表最大。
展开解析

经验分布 Fₙ(y)=累计个数/n（n=12），逐点算双列差值：最大者在 y=26⁻ 处 |0.3333−0.6465|=0.3132（答案 D）。易错：只用左极限或只看数据点处，漏掉「死亡前一瞬间」的跳跃前取值。

χ² 真题：40 个损失数分组，f(x)=x⁻²（x>1），算各组概率 pᵢ=∫f，χ²=Σ(Oᵢ−40pᵢ)²/(40pᵢ)≈7.2（答案 C）。注意最后开区间 (4,∞) 的概率=1−F(4)。

选择口诀：分组数据用 χ²，完整连续用 K–S（小样本）/卡方（大样本分组），重尾敏感用 A–D；参数是估出来的 → 自由度要扣、K–S 临界值要修正。

M4模型选择：从候选到唯一 中频★★

三层选择法：① 直观选择——p–p 图 / Q–Q 图目测（p–p 比较分布函数，Q–Q 比较分位数，Q–Q 对尾部更敏感）；② 打分法——AIC=−2ℓ+2k，BIC=−2ℓ+k·ln(n)（BIC 惩罚更重，n>e²≈8 后倾向选更简模型）；③ 假设检验——嵌套模型用似然比检验 LR=2(ℓ₁−ℓ₀)~χ²(参数差个数)。
警示：AIC/BIC 比较必须基于同一样本、同一似然口径（截断/删失处理一致），否则 ℓ 不可比；K–S、χ² 也一样——「换样本即换赛跑」。

M5修匀理论：让生命表变光滑 低频★

原始死亡率估计带抽样噪声，直接用会锯齿。修匀 = 在拟合优度与光滑度之间做权衡。
表格修匀 Whittaker–Henderson：min Σ wᵢ(q̂ᵢ−qᵢ)² + Σ λ(Δkqᵢ)²
参数修匀：Gompertz μx=B·cx；Makeham μx=A+B·cx
拟合度检验：χ² = Σ(q̂ᵢ−qᵢ)²/Var(q̂ᵢ)
第一项管拟合、第二项管光滑，λ 越大越光滑；Gompertz 是纯老化，Makeham = Gompertz + 常数意外死亡率。
口诀：「Whittaker 一半数据一半脾气」——w 管数据、λ 管脾气；参数修匀记两个名字：Gompertz 纯老化，Makeham = Gompertz + 常数（意外死亡率）。

M6信度理论：数据不够，先验来凑 中频★★

有限波动（完全信度）：均值类 n ≥ (zα/2/k)²·(σ/μ)²；频率类 n ≥ λ·(z/k)²
Bühlmann：Z = EPV/(EPV+VHM)，预测 = Z·x̄ + (1−Z)·μ
Bühlmann–Straub：Z = Σwᵢ/(Σwᵢ + K)，K = EPV/VHM
贝叶斯（泊松–伽马）：后验均值 = (α + Σxᵢ)/(β + n)
泊松频率类取 z=1.96、k=0.05 时 n ≈ 1537；暴露不等时用 Bühlmann–Straub。
高频信度因子综合题 Bühlmann 模型：EPV 与 VHM 由 ANOVA 分解——总方差 = E[Var(X|Θ)] + Var(E[X|Θ])，前者是 EPV，后者是 VHM。
骨架：Z=EPV/(EPV+VHM)；K=EPV/VHM；预测 = Zx̄+(1−Z)μ。
展开详尽解答

方差分解恒等式是信度题的「总开关」：题给各风险组内方差均值与组间方差 → 直接拆出 EPV、VHM → Z。若 Z′=√0.32≈0.566（有限波动口径按 n/n₀ 或题给折算），则预测值 = 0.566×样本经验 + 0.434×先验——上一轮已入 CH.02 题库精粹。

泊松–伽马共轭（贝叶斯信度）：先验 Γ(α,β)，观测 Σxᵢ → 后验 Γ(α+Σxᵢ, β+n)，后验均值 (α+Σxᵢ)/(β+n)。书 P305 真题：后验=(8+e²)/(4+e²) 即此公式（α=8? 按题面）——**共轭先验的两行公式必须背**：形状加数据、率加样本量。

三信度一句话：有限波动管「数据够不够多」，Bühlmann 管「数据与先验怎么配」，贝叶斯管「先验分布长什么样」。考试最爱：方差分解 → Z → 加权预测，一条链。

M7一页总览：模型生命周期

数据 → 经验模型（K–M / N–A）→ 参数模型（选分布族）→ 估计（矩 / MLE / 分位数）→ 检验（χ² / K–S / A–D）→ 选择（AIC / BIC / LR）→ 修匀（Whittaker / 参数曲线）→ 信度（个体×总体加权）→ 上线监控。每一步都有「不做会怎样」：不修匀→费率抖动；不信度→小样本定费率过拟合；不检验→模型带病上线。
